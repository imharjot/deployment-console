# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: we pledge to make participation in this project a harassment-free experience for everyone. Be respectful
and constructive, assume good intent, and focus on what is best for the community. Harassment, insults, personal or
political attacks, publishing others' private information and other conduct that would be inappropriate in a
professional setting are not acceptable.

The full text of the Contributor Covenant 2.1 — including our standards, the enforcement responsibilities of the
maintainers and the enforcement guidelines — applies to all project spaces (issues, pull requests, discussions and any
other channel run by the project) and to anyone representing the project elsewhere.

## Reporting

Report unacceptable behaviour privately to the project maintainers (for example through a private message to a
maintainer on GitHub). All reports are reviewed and investigated promptly and fairly, and the maintainers respect the
privacy and security of the reporter.
